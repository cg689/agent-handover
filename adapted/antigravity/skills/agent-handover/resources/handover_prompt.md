请把项目现状写成精简版交接文档 HANDOVER.md，放在项目根目录（若已有旧文档请先备份归档至 docs/handover/），并在顶部包含元信息头：

---
交接状态: PENDING
交接时间: YYYY-MM-DD
交出方: [当前 Agent 名称]
接收方: [目标 Agent 名称 / 待定]
---

文档内容至少包括：
1. 项目简介（是什么、给谁用的）
2. 技术栈（语言、框架、主要依赖）
3. 常用命令（安装依赖 / 跑测试 / 构建 / 部署）
4. 当前进度（已完成 / 进行中 / 待做）
5. 已知问题与技术债
6. 持久化数据与缓存（本地数据库/路径等）

注意：不要写入任何明文密钥、Token、私网 IP 或真实业务测试数据。
